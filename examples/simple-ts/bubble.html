AGO — Floating bubble widget

The blue button in the bottom-right corner is the widget. It is the hosted embed widget without the iframe: a teaser bubble, then a panel with a home screen, the conversation, and the chat history. This page answers from the public demo account, no signup needed.

Install it on your site

  1. Add the SDK to your project: 
    npm install @useago/sdk
  2. Mount the bubble once, anywhere your page scripts run (see src/bubble.ts for this page's version): 
    import { mountChatWidget } from "@useago/sdk/widget";

mountChatWidget(document.body, {
  config: { baseUrl: "https://playground.api.useago.com", agent: "generic-guide" },
  placement: "bubble",
  title: "Ask AGO",
  prompt: "Hello, how can I help you today?",
  subtitle: "Answers come from the **AGO docs**.",
  conversationStarters: [
    { label: "What can the SDK do?" },
    { label: "Pricing", message: "Tell me about pricing" },
  ],
  colors: { button: "#007bff", header: "#03182f" },
});
  3. Swap baseUrl for your own https://YOUR-DOMAIN.api.useago.com and agent for one of your agent slugs.
  4. No build step? Import from a CDN instead: 
    <script type="module">
  import { mountChatWidget } from "https://esm.sh/@useago/sdk@1/widget";
  mountChatWidget(document.body, { placement: "bubble", config: { baseUrl: "..." } });
</script>

What to try

  • Click the launcher, or the teaser bubble, to open the panel.
  • Click a starter card or type a question: the conversation screen opens.
  • Use the back chevron, then the Chats tab: the thread is listed with a relative time.
  • Reload the page within two hours: the last thread reopens by itself.
  • Narrow the window under 450px: the panel goes full screen.
  • Ask to talk to a human: on a tenant with the ticketing tool, the ticket form appears in the conversation.

Options, theming tokens and the ticket form are documented in docs/general/widget.md, section "Floating bubble".
